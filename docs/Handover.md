This document is should assist any future teams working on Network Traffic Analysis. It contains information about how to use and develop on the program, some potential next steps if you're uncertain where to start, and any known issues that remain after this year's final release.

# Project Details
This project is split into two main programs:

 - A mostly Python-based packet capturing and analysis tool (`NTAnalyser`)
 - A Go project and executable that (very fundamentally) analyses `.pcap` files (`CLI Tool`)

NTAnalyser is the main focus of development, and has considerably more features, with the CLI Tool acting as a prototype in a faster-running language. All code can be found in the `src` directory.

## NTAnalyser
To run the NTAnalyser, run the provided shell scripts: `build.sh` (only necessary if you want to run the analysis webpage) and `nta.sh`. Required arguments for `nta.sh` should be explained when you try to run it. If these scripts don't work, you can manually start the webserver by running `main.go` in the `src/analysis/backend` directory using `go run main.go`. To run the main program without the shell script, use `python src/main.py --analysis --monitor --promiscuous` in the root directory, where the `--analysis` argument represents whether you want to run analysis in the background, and the `monitor` and `promiscuous` arguments represent if you want to capture packets only on your local machine or in your whole network.  There is a [usage guide webpage](https://tomossherlock.github.io/NetworkTrafficAnalysis/#/README).

Acting as the main focus for development, the mostly Python-based NTAnalyser captures and displays packet information (similar to Wireshark) and can analyse captured packets for signs of various cyberattacks via a local webpage.

The main functionality of the packet capturing uses the Python library `scapy`. To capture packets, the program also requires the host machine to have installed a packet capturing tool, such as `npcap`. Captured packets are decoded and their layer information is stored in dataframes for the GUI to use. The main GUI utilises Python code generated by `.ui` files. 

NTAnalyser can also run analysis on packets. To do this, the local webserver needs to be running. On the created webpage, attack analyses and graphs are shown, each with a brief explanation on why the analysis would find any addresses suspicious.

The packet capture, analysis functions and usage guide webpage are all tested in their respective test files.
