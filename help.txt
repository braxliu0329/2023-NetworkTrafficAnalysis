Network Traffic Analysis (NTA) is a packet sniffing tool which provides detailed analyses and graphs of your network.

Usage: 
    ./nta.sh [--analysis] [--monitor | --promiscuous]  
    ./nta.sh
    ./nta.sh -h | --help
    ./nta.sh --version

Options: 
    -h --help           Show usage instructions
    --monitor           Run sniffer in monitor mode (Disabled by default)
    --promiscuous       Run sniffer in promiscuous mode (Disabled by default)
    --analysis          Enable web server for analysis (Disabled by default)
    --version           Show version
